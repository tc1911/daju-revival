## 1. 构建链

构建入口只有 `tools/build.py`；阶段、补丁顺序、资源/原生步骤都在 `tools/pipeline.toml`。
旧的 `build_official_arm64_*.sh` 已删除（git 历史可查）。

```bash
tools/build.py list                 # 阶段/补丁/产物
tools/build.py                      # 默认 profile-native
tools/build.py nopay
tools/build.py back                 # 会先重跑 nopay
tools/build.py daily
tools/build.py shop
tools/build.py profile
tools/build.py profile-native --force   # 从 merge 起重跑整链
tools/build.py daily --no-deps          # 只用现有 back，不重跑上游
```

阶段：

| stage | 表里的步骤 | 产物 |
|---|---|---|
| `nopay` | `offline → local → monetization → album` | `official-arm64-local-nopay.apk` |
| `back` | `back_button` + `native.back`（apktool/smali） | `official-arm64-back.apk` |
| `daily` | `daily_currency` + `assets.daily_currency` | `official-arm64-daily.apk` |
| `shop` | `rmb_shop` | `official-arm64-shop.apk` |
| `profile` | `custom_profile → settings_cleanup → chat_image` + `main_js` | `official-arm64-profile.apk` |
| `profile-native` | `dex.profile_bridge`（`classes3.dex`） | `official-arm64-profile-native.apk` |

历史 stage 也在表里：`offline`、`local`、`profile-js`、`noshop`。

规则：

- `tools/build.py` 需要 Python 3.11+（标准库 `tomllib`）
- 改补丁：改 `[patches.<id>]`，再把 id 加进目标 `stage.patches`；顺序就是 JS 链顺序
- 改资源/原生步骤：改 `[assets.*]`/`[native.*]`，不要在 `build.py` 里加特例
- 改上游补丁后：`tools/build.py profile-native --force`；只改下游可用 `--no-deps`，但要确保 base 是最新的
- `back.rebuild_base = true`：构建 back 会自动重跑 nopay 与 merge；`profile-native.rebuild_base = true`：默认重跑 profile 的 JS 链再打 dex
- merge 默认使用 `compat/arm64-v8a/`（7 个库），只有 compat 不完整时才回退 OPPO APK
- `profile-native` 的 d8 默认用 `/usr/lib/jvm/zulu-11/bin/java` + `/opt/android-sdk/build-tools/37.0.0/lib/d8.jar`，否则退回 PATH 的 `d8`
- overlay 相对路径必须等于 APK 内路径（如 `assets/src/project.jsc`、`classes3.dex`）
- `main.js` 启动时必须清 `HotUpdateSearchPaths` 与 `blackjack-remote-asset`，否则旧热更 JS 覆盖 APK
- `work/tmp` 保留：`project.*.js`、`main_nohot.js`、`native_profile/android.jar`、
  `official_back_full/`、`apktool_framework/`；截图/日志/中间 APK 可删

## 3. 已知问题

**内容/功能残留**

- 启动日志仍有 `jsb-videoplayer.js not found`（官方包缺视频模块）
- 深度氪金/充电残留：剧情内购买按钮、累计充值展示、自动使用充电宝设置
- `MiniGameUI` 仍有残留氪金入口；`enterNewChapter` 仍保留买电池引导
- `remove_monetization` 已删 `FeedBack_1` 问卷与 `FeedBack` 客服两个入口
- `exchange` 兑换协议未被离线补丁拦截，离线点击会请求失败
- `assets/main.js` 只是启动清缓存，原热更引导代码仍在
- 电池 HUD 是自绘覆盖，不替换原图标；头像裁剪是自动居中，不是可拖动框
- 每日签到按设备本地日期判断；改系统时间可以重复领，属离线存档的已知取舍

**代码/构建**

- `chat_image_fallback_patch.py:62` 的 `\.png` 是 Python 非法转义，当前只告警，
  未来 Python 可能直接报错
- `chatStorage.getNpcGiftItem` 在 `_npcFavors[e]` 不存在时可能抛异常
- `BaseProxy.sendHttpMsg` 调 `App.HTTP`，App 实际暴露 `Http`，疑似死代码
- `[native.back]` 的 `official_back_full` 是缓存；smali 改动后用
  `tools/build.py back --force-native` 重新解包/打补丁
- `compat/arm64-v8a` 缺 `libsgcore.so` 的 arm64 版本；OPPO 渠道库 `libads-c`/`libnearmelog` 未包含
- `daily_currency_assets.py` 的 glob 是硬编码相对路径，必须在仓库根目录跑
- `[native.profile_bridge]` 缺 `android.jar` 时会联网下载；离线环境需预先放好

## 4. 验证

装包前先核对产物：

```bash
# 环境变量见 README「环境变量」：JSC_KEY、KS、KS_PASS
# 构建表自检 + 整链可复现（会重建中间产物，最终输出到临时路径）
tools/build.py list
tools/build.py profile-native --force --out work/tmp/repro.apk
sha256sum work/tmp/repro.apk work/out/official-arm64-profile-native.apk
# 两条 SHA256 应一致

# 签名 / 包名 / ABI
apksigner verify --print-certs work/out/official-arm64-profile-native.apk
aapt dump badging work/out/official-arm64-profile-native.apk | grep -E 'package:|native-code:'
adb shell dumpsys package com.happyelements.xstorycncatdetective | grep -E 'primaryCpuAbi'

# APK 内 JS 与构建产物一致
unzip -p work/out/official-arm64-profile-native.apk assets/src/project.jsc > /tmp/apk_project.jsc
python3 tools/jsc.py decrypt /tmp/apk_project.jsc /tmp/apk_project.js
cmp /tmp/apk_project.js work/tmp/project.final.js && echo 'JS 一致'
```

装机与启动：

```bash
adb install -r work/out/official-arm64-profile-native.apk
adb logcat -c
adb shell am start -n com.happyelements.xstorycncatdetective/org.cocos2dx.javascript.PremissionSplashActivity
adb logcat | grep -E 'HotUpdate|!!!!HotUpdate'
```

日志锚点：

- `!!!!HotUpdate main.js no hotUpdateSearchPaths`：旧热更 JS 不会覆盖 APK
- `!!!!HotUpdate skip login_getClientConfig (offline)`：没有等 102 秒启动检查

其他检查：

- 重启后设置/剧情进度仍在（`UserDefault` 落盘）
- 聊天图片 1.5s 内出图或 toast，不应停在 1px + 全屏遮罩
- 返回键：关于页/大图 → UI 栈 → “我/发现”回聊天 → 聊天 tab 才弹退出
- 设置页只剩 5 项，关于页正文完整、返回/遮罩可关闭，底部 footer 贴底

## 5. 维护规则

1. 修改记录只更新本文件；工具/补丁实现进 `docs/代码文档.md`，游戏模块进
   `docs/游戏代码文档.md`，原版机制进 `docs/原版代码分析.md`

   只改下游 patch 才用 `tools/build.py <stage> --no-deps`
3. 装包后先确认日志锚点，并核对 APK 内 `project.jsc` 与 `work/tmp/project.final.js`
4. 涉及持久化时先确认 `UserDefault` 是否落盘，不要再用 UI 快照补
5. 清理 `work/tmp` 只删截图/日志/中间 APK，保留第 1 节列出的构建缓存
6. 改阶段/补丁顺序只改 `tools/pipeline.toml`，不要新增 `build_*.sh`
